SIGNAL FORMAT — WebSocket JSON
Connect to wss://rf.postoccupancy.com or wss://10.0.0.1:3000
Every broadcast is a JSON object. Two types:

osc — physical sensor, originated as OSC UDP:
{
  "type": "osc",
  "device": "osc/pi-hc-sr04/distance-cm",
  "value": 142.3,
  "min": 5,
  "max": 400
}
json — browser or HTTP origin, full float:
{
  "type": "json",
  "device": "json/esp32-am2320/temp_c",
  "value": 23.45
}
midi — MIDI controller via WebMIDI API or Pi USB:
{
  "type": "midi",
  "device": "midi/Teensy MIDI",
  "msgType": "cc",
  "channel": 3,
  "cc": 1,
  "value": 64
}
OSC — automatic on port 9000
Every connected browser client automatically receives all signals
as OSC UDP on port 9000. Open your OSC listener on port 9000.

OSC address format:
/sensor/esp32-am2320/temp_c  23.45  0.845
/midi/Teensy_MIDI/ch3/cc1    0.504  64
/midi/mic-192_168_0_5/centroid  0.703  89
Sensor messages: raw float value + normalized 0–1
MIDI CC messages: normalized 0–1 + raw 0–127

TouchDesigner: OSC In CHOP → port 9000
VCV Rack: VCV OSC module → port 9000
Max for Live: udpreceive 9000
PYTHON — WebSocket JSON
pip install websockets
import asyncio, websockets, json

async def listen():
    url = "wss://rf.postoccupancy.com"
    async with websockets.connect(url) as ws:
        async for msg in ws:
            data = json.loads(msg)
            if data["type"] == "osc":
                print(data["device"], data["value"])
            elif data["type"] == "json":
                print(data["device"], data["value"])
            elif data["type"] == "midi":
                print(data["device"], data["value"] / 127)

asyncio.run(listen())

SENDING OSC TO THE ROUTER
OSC UDP is accepted on port 5005 (local network only —
not available via rf.postoccupancy.com).
Use Tailscale for remote OSC send.
Message format: /sensor/name/param value
e.g. /sensor/kinect/x 0.42
